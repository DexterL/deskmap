# 数据文件格式规范

本文档描述 `seats-tool.html` 导出/导入 JSON 文件的数据结构。符合此规范的 JSON 文件可直接导入工具，还原完整的画布设计。

## 快速示例

```json
{
  "version": 1,
  "people": [
    { "id": "id_lichunping", "name": "李春平", "color": "#e74c3c" }
  ],
  "seats": [
    { "id": "id_xxx", "x": 120, "y": 90, "orientation": 0, "personId": "id_lichunping" }
  ],
  "obstacles": [
    { "id": "id_yyy", "x": 300, "y": 150, "w": 60, "h": 60, "name": "柱子 A" }
  ],
  "nextColorIdx": 1
}
```

## 顶层字段

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `version` | `number` | 是 | Schema 版本号，当前为 `1` |
| `people` | `Array<Person>` | 是 | 所有人员（无论是否入座） |
| `seats` | `Array<Seat>` | 是 | 所有已放置的座位 |
| `obstacles` | `Array<Obstacle>` | 是 | 所有已放置的障碍物 |
| `nextColorIdx` | `number` | 是 | 下一个新增人员使用的颜色索引 |

> 缺少 version 字段会被视为旧版数据并允许导入；version 存在但不为 1 时将拒绝导入并提示版本不兼容。

## 实体定义

### Person（人员）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `id` | `string` | 是 | 唯一标识，以 `id_` 开头（如 `id_abc123`）。可自行定义有意义的 ID |
| `name` | `string` | 是 | 显示名称，最长 20 字符 |
| `color` | `string` | 是 | 人员标识色，Hex 格式（如 `#e74c3c`），从 20 色调色板中选取 |

约束：
- `id` 在整个文件内必须唯一（people、seats、obstacles 的 id 各不相同）
- `name` 不能为空字符串

### Seat（座位）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `id` | `string` | 是 | 唯一标识，以 `id_` 开头 |
| `x` | `number` | 是 | 左上角 X 坐标（像素），网格对齐的整数 |
| `y` | `number` | 是 | 左上角 Y 坐标（像素），网格对齐的整数 |
| `orientation` | `number` | 是 | 朝向角度，必须是 8 个方向之一（见下表） |
| `personId` | `string\|null` | 是 | 占用此座位的人员 ID，空位时为 `null` |

尺寸约束：
- 座位固定宽 90px、高 60px（即 3×2 网格单元）
- `x` 和 `y` 必须是 30 的整数倍（网格对齐），推荐使用 `Math.round(raw / 30) * 30`

#### 朝向系统

朝向通过 CSS `transform: rotate(Ndeg)` 实现。4 个方向的角度值：

| 值 | 方向 | 标签 |
|----|------|------|
| `0` | 上 (Up) | ↑ |
| `90` | 右 (Right) | → |
| `180` | 下 (Down) | ↓ |
| `270` | 左 (Left) | ← |

> 座位一旦放置在工作区，朝向不可更改。如需调整方向，需删除后重新从待定席拖入。

### Obstacle（障碍物）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `id` | `string` | 是 | 唯一标识，以 `id_` 开头 |
| `x` | `number` | 是 | 左上角 X 坐标（像素），网格对齐的整数 |
| `y` | `number` | 是 | 左上角 Y 坐标（像素），网格对齐的整数 |
| `w` | `number` | 是 | 宽度（像素），网格对齐的整数，最小 30 |
| `h` | `number` | 是 | 高度（像素），网格对齐的整数，最小 30 |
| `name` | `string` | 是 | 障碍物名称，显示在工作区中；双击可编辑 |

约束：
- `w` 和 `h` 必须是 30 的整数倍
- 最小尺寸为 30×30（1×1 网格单元）
- 名称不能为空字符串（导入时为空会被替换为 "障碍物"）

工具内置的预制模板尺寸（仅供创建时参考，非限制）：

| 标签 | 网格单元 | 像素尺寸 |
|------|---------|---------|
| 1×1 | 1×1 | 30×30 |
| 2×1 | 2×1 | 60×30 |
| 1×2 | 1×2 | 30×60 |
| 2×2 | 2×2 | 60×60 |
| 3×1 | 3×1 | 90×30 |
| 1×3 | 1×3 | 30×90 |
| 3×3 | 3×3 | 90×90 |

用户还支持使用"自定义尺寸"模式在工作区中自由拖拽创建任意尺寸（30 的整数倍）的障碍物。

## 网格系统

- **单元格大小**: 30×30px
- **座位尺寸**: 3×2 格 = 90×60px
- **坐标对齐**: 所有 `x`、`y`、`w`、`h` 值必须为 30 的整数倍
- **对齐算法**: `Math.round(clientX / 30) * 30`
- **工作区默认尺寸**: 1800×1200px（会根据内容自动扩展）
- **座位数量上限**: 200 个

## 碰撞规则

- 使用 AABB（轴对齐包围盒）碰撞检测
- **共享边界的相邻元素不视为碰撞**（即 `a.right == b.left` 不触发碰撞）
- 碰撞检测在以下操作时触发：放置座位、放置障碍物、自定义障碍物创建
- 碰撞的元素类型：座位⇄座位、座位⇄障碍物、障碍物⇄障碍物
- 碰撞发生时，操作被阻止并出现红色闪烁提示

## 人员与座位的关系

- 一个座位最多容纳 1 人
- 一个人最多占用 1 个座位
- 未入座人员（`personId` 未被任何座位引用）出现在左侧面板的"人员清单"中
- 首次打开页面时人员清单为空，需通过「导入」加载 JSON 数据文件来填充

## 颜色系统

工具使用 20 色调色板循环分配人员颜色：

```json
[
  "#e74c3c", "#3498db", "#2ecc71", "#f39c12", "#9b59b6",
  "#1abc9c", "#e67e22", "#2980b9", "#27ae60", "#c0392b",
  "#8e44ad", "#16a085", "#d35400", "#2c3c50", "#f1c40f",
  "#00bcd4", "#ff5722", "#795548", "#607d8b", "#e91e63"
]
```

- 新增人员时，颜色索引从 `nextColorIdx` 开始，循环取色（`PERSON_COLORS[nextColorIdx % 20]`）
- 人员入座后，座位标签文字颜色根据背景色亮度自动选择 `#333`（亮底）或 `#fff`（暗底）
- 手动指定 `color` 时不需要来自调色板，任何 Hex 色均可

## ID 命名约定

| 前缀 | 来源 | 示例 |
|------|------|------|
| `id_` | 导入数据或手动添加 | `id_abc123`, `id_zhangsan` |

> ID 可自行定义有意义的名称（如 `id_zhang_san`），只要在整个文件内唯一即可。工具自动生成的 ID 格式为 `id_` + 时间戳 + 随机字符。

## Schema 版本历史

| 版本 | 变更 |
|------|------|
| 1 | 初始版本 |

## 完整示例

```json
{
  "version": 1,
  "people": [
    { "id": "id_lichunping", "name": "李春平", "color": "#e74c3c" },
    { "id": "id_lihaolin", "name": "李昊林", "color": "#3498db" },
    { "id": "id_lijijing", "name": "李济景", "color": "#2ecc71" },
    { "id": "id_lijinnuo", "name": "李金诺", "color": "#f39c12" },
    { "id": "id_new_employee", "name": "新员工", "color": "#e91e63" }
  ],
  "seats": [
    {
      "id": "id_seat_01",
      "x": 120,
      "y": 90,
      "orientation": 0,
      "personId": "id_lichunping"
    },
    {
      "id": "id_seat_02",
      "x": 240,
      "y": 90,
      "orientation": 90,
      "personId": "id_lihaolin"
    },
    {
      "id": "id_seat_03",
      "x": 120,
      "y": 180,
      "orientation": 180,
      "personId": null
    },
    {
      "id": "id_seat_04",
      "x": 240,
      "y": 180,
      "orientation": 270,
      "personId": null
    }
  ],
  "obstacles": [
    {
      "id": "id_b1",
      "x": 300,
      "y": 60,
      "w": 90,
      "h": 90,
      "name": "承重柱"
    },
    {
      "id": "id_b2",
      "x": 60,
      "y": 300,
      "w": 60,
      "h": 30,
      "name": "文件柜"
    }
  ],
  "nextColorIdx": 5
}
```

导入上述文件后，工作区将渲染出：
- 5 人（其中 2 人已入座，2 个空位，1 人在等待清单）
- 4 个座位（含两种朝向的已占用和空位）
- 2 个障碍物（承重柱 90×90、文件柜 60×30）
