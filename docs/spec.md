# DeskMap — 工位规划设计工具

## 一、需求概述

一个纯浏览器端工位布局规划工具，用于在矩形平面图中模拟座位的摆放、人员的分配和调整。所有操作在浏览器中完成，无需服务端。

---

## 二、功能需求

### 2.1 座位管理

| 编号 | 需求 | 说明 |
|------|------|------|
| S1 | 网格对齐摆放 | 工作区为 30×30px 网格，所有元素吸附到网格交叉点 |
| S2 | 4 方向朝向 | 座位支持上 / 下 / 左 / 右四个朝向 |
| S3 | 待定席预制 | 待定席提供 4 个朝向的预制座位模板 |
| S4 | 拖入工作区 | 从待定席按住座位拖入工作区，松手放置 |
| S5 | 不可旋转 | 座位拖入工作区后不可再调整朝向，需朝向正确时拖入 |
| S6 | 碰撞检测 | 座位与座位、座位与障碍物不可重叠，放置时检测并阻止 |
| S7 | 沙发样式 | 座位视觉呈沙发形态，有明显的背靠面和朝向箭头 |
| S8 | 规模上限 | 不超过 200 个座位 |
| S9 | 快速复制 | 悬停在座位上显示 4 向箭头，点击可直接在相邻位置复制相同座位 |

### 2.2 障碍物管理

| 编号 | 需求 | 说明 |
|------|------|------|
| O1 | 常见尺寸 | 提供 1×1、2×1、1×2、2×2、3×1、1×3、3×3（单位：30px 网格单元）|
| O2 | 拖入工作区 | 从待定席拖入，与座位同网格吸附 |
| O3 | 命名 | 双击障碍物可编辑名称 |
| O4 | 碰撞检测 | 障碍物与座位/障碍物不可重叠 |
| O5 | 快速复制 | 悬停在障碍物上显示 4 向箭头，点击可直接在相邻位置复制相同障碍物 |

### 2.3 人员管理

| 编号 | 需求 | 说明 |
|------|------|------|
| P1 | 人员清单 | 左侧面板显示所有未入座人员 |
| P2 | 独立颜色 | 每人分配独立颜色（20 色调色板循环），以颜色圆点标识 |
| P3 | 视觉友好 | 显示姓名，颜色圆点 + 文字标签 |
| P4 | 添加/删除 | 支持动态添加和删除人员 |
| P5 | 预置数据 | 首次使用预置 27 人名单 |

### 2.4 拖拽交互

| 编号 | 需求 | 说明 |
|------|------|------|
| D1 | 拖人入座 | 从待选清单拖动人员到空座位，人员入座后座位变色 |
| D2 | 拖人出座 | 从已占用座位拖动人员到空白区域，人员回归待选清单 |
| D3 | 人员交换 | 已入座人员 A 拖到已入座人员 B 的座位上，自动互换座位 |
| D4 | 拖拽反馈 | 拖动时显示半透明幽灵元素；悬停目标座位高亮；非法放置红色闪烁 |
| D5 | 取消拖拽 | Esc 键取消当前拖拽操作 |
| D6 | 边缘滚动 | 拖动到工作区边缘时自动滚动 |

### 2.5 删除操作

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 直接删除 | 右键点击座位/障碍物直接删除，不再弹出菜单 |
| R2 | 删除座位 | 若座位有人，人员自动回归待选清单 |
| R3 | 删除障碍物 | 直接移除 |

### 2.6 数据持久化

| 编号 | 需求 | 说明 |
|------|------|------|
| T1 | 自动保存 | 每次状态变更自动写入 localStorage |
| T2 | 导出 JSON | 工具栏按钮，下载 `.json` 文件 |
| T3 | 导入 JSON | 工具栏按钮，选择 `.json` 文件导入恢复 |
| T4 | 清空工作区 | 清除全部座位和障碍物，保留人员清单 |

## 三、技术设计

### 3.1 技术选型

| 决策 | 选择 | 理由 |
|------|------|------|
| 架构 | 单 HTML 文件 | 用户要求"浏览器直接打开即可加载" |
| 框架 | 无，Vanilla JS | 零依赖，无需构建 |
| 拖拽方案 | Pointer Events API | 比 HTML5 Drag API 控制更精确，支持自定义幽灵元素 |
| 样式 | CSS 内嵌 | 保持单文件自包含 |
| 持久化 | localStorage + File API | 自动保存 + 手动导出导入 |

### 3.3 数据模型

```javascript
{
  people: [
    {
      id: "preset_0",       // 唯一标识
      name: "李春平",        // 显示名称
      color: "#e74c3c"      // 个人颜色 (hex)
    }
  ],
  seats: [
    {
      id: "id_xxx",         // 唯一标识
      x: 120,               // 网格 X 坐标 (px, CELL 的倍数)
      y: 90,                // 网格 Y 坐标
      orientation: 0,       // 朝向角度: 0|90|180|270
      personId: "preset_0"  // 占用人员 ID，null 为空
    }
  ],
  obstacles: [
    {
      id: "id_xxx",         // 唯一标识
      x: 300,               // 网格 X 坐标
      y: 150,               // 网格 Y 坐标
      w: 60,                // 宽度 (px, CELL 的倍数)
      h: 60,                // 高度 (px)
      name: "柱子 A"        // 障碍物名称
    }
  ],
  nextColorIdx: 27          // 下一个人员使用的颜色索引
}
```

### 3.4 网格系统

- **单元格**：30×30px
- **座位尺寸**：3×2 单元格 = 90×60px
- **坐标规范**：所有坐标强制为 CELL(30px) 的整数倍
- **吸附算法**：`Math.round(clientX / CELL) * CELL`
- **网格渲染**：CSS `background-image` 双层 `linear-gradient` 绘制

### 3.5 关键算法

#### 碰撞检测（AABB）

```
rectsOverlap(a, b):
  return NOT ( a.right <= b.left OR b.right <= a.left
            OR a.bottom <= b.top OR b.bottom <= a.top )
```

当要放置元素时，遍历现有 seats + obstacles 逐一检测重叠。共享边界（紧邻）不计为碰撞。

#### 拖拽状态机

```
                  pointerdown
  IDLE ──────────────────────────────► DRAGGING
   ▲                                      │
   │  pointerup (on target)               │ pointermove
   │  or Escape                           │
   │                                      ▼
   └──────────────────────────────── DRAGGING
          (commit / cancel)           (ghost follows cursor,
                                       highlights targets,
                                       auto-scrolls edges)
```

#### 交换逻辑

```
drag assigned-person from Seat A → drop on Seat B (occupied):
  1. 从 Seat A 移除 person_A（拖拽开始即时生效）
  2. 取出 Seat B 上的人员 person_B
  3. person_A 分配到 Seat B
  4. person_B 分配到 Seat A  ← 完成交换
```
