# DeskMap — 工位规划设计工具
  
  纯浏览器端工位布局规划工具，零依赖单 HTML 文件，双击即用。
  
  ## 快速开始
  
  用浏览器直接打开 `deskmap.html` 即可。  
  通过「导入」加载 JSON 数据文件来填充人员和布局，或使用界面中的输入框逐一手动添加。
  
  ## 功能特性

- **座位布局**：网格吸附，提供 4 个朝向的沙发样式座位，支持快捷键旋转。
- **对象旋转**：选中或拖拽对象时，按 `R` 键可进行顺时针 90° 旋转，具备碰撞预测。
- **批量操作**：支持画布框选（Marquee Selection），可同时选中多个对象进行批量搬运。
- **座位拖拽**：已放置的对象可自由拖拽移动，具备碰撞检测和网格对齐功能。
- **障碍物**：7 种常见尺寸，支持自定义拖拽划定尺寸，双击可编辑名称。
- **人员管理**：支持分组设计，按分组统一管理人员颜色，支持批量添加、一键清空。
- **颜色系统**：基于分组的 20 色调色板，修改分组颜色将同步更新所有所属人员。
- **智能交换**：拖拽人员到已占用座位时自动互换，支持从列表或座位发起。
- **快速批量设计**：悬停在已放置的对象上，点击出现的方向箭头可直接在相邻位置复制相同对象（带碰撞检测）。
- **快速删除**：右键点击座位或障碍物直接删除，无需二次确认。
- **数据导出**：localStorage 自动保存，支持 JSON 导出/导入（版本化 schema）。
- **数据格式**：详见 [docs/data-schema.md](docs/data-schema.md)

## 技术栈

纯 HTML/CSS/JS，无框架，无构建工具，无外部依赖。
