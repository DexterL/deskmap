# 工位规划设计工具 (Seats Tool)

纯浏览器端工位布局规划工具，零依赖单 HTML 文件，双击即用。

## 快速开始

用浏览器直接打开 `seats-tool.html` 即可。  
通过「导入」加载 JSON 数据文件来填充人员和布局，或使用界面中的输入框逐一手动添加。

## 功能特性

- **座位布局**：网格吸附，从待定席拖入 8 个朝向的沙发样式座位。椅子外观设计，通过形状表达朝向
- **座位拖拽**：已放置的座位可拖拽移动，含碰撞检测
- **障碍物**：7 种常见尺寸（1×1 至 3×3），支持自定义拖拽尺寸，双击命名
- **人员管理**：支持单个添加、批量粘贴（逗号/换行分隔）、清空
- **颜色系统**：20 色调色板，添加时可自由选择，添加后可修改为未使用的颜色
- **智能交换**：拖拽已入座人员到另一个已有人的座位时自动互换
- **右键删除**：右键座位/障碍物弹出删除菜单
- **持久化**：localStorage 自动保存，支持 JSON 导出/导入（版本化 schema）
- **数据格式**：详见 [docs/data-schema.md](docs/data-schema.md)

## 技术栈

纯 HTML/CSS/JS，无框架，无构建工具，无外部依赖。
